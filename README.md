## 2. Giới thiệu bài thực hành

Lab 07 – Advanced CSS: Layout gồm 19 bài thực hành,
tập trung vào các kỹ thuật xây dựng bố cục,
thiết kế giao diện responsive và tạo hiệu ứng CSS.

Thông qua bài thực hành, sinh viên tìm hiểu cách
định vị phần tử, xây dựng bố cục nhiều cột,
sử dụng Media Queries, CSS Transforms,
Transitions, Filters, Animations và Bootstrap.
